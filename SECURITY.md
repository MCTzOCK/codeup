# Sicherheitsrichtlinie

## Unterstützte Versionen

Die EINZIGE unterstützte Version ist zu JEDER Zeit die aktuelle Version des `develop`-Zweigs. Jeder andere Versionszweig (`vX.Y.Z`) dient nur als Referenz.

## Sicherheitslücke Melden

Um eine Sicherheitslücke zu melden, kann das Kontakt-Formular unter https://codeup.space/codeup/contact verwendet werden. Damit die Kontaktanfrage als gemeldete Sicherheitslücke gilt, muss die Kategorie "Fehler melden" ausgewählt sein.
